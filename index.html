Le principe

Pas juste se plaindre. Proposer mieux.

ParoleLycéenne est un espace de consultation autour de propositions concrètes. Le but n'est pas de prétendre qu'une solution est parfaite, mais de faire émerger des idées discutées, réalistes et améliorables.

Les votes indiquent les avis exprimés sur le site : ils ne représentent pas automatiquement tous les lycéens de France.
